# Заметки для Claude Code в этом репозитории

## Открытый дизайн-долг — напоминай владельцу при следующих работах

По прямому запросу владельца (11.08.2026): при следующей работе над продуктом
(особенно если это снова разбор аудита или планирование задач) — напомнить,
что в `ROADMAP.md` (раздел «Дизайн — открытый долг») висят три пункта,
заявленные ещё в ТЗ v4.1, но ни разу не взятые в работу:

1. Тёмная тема
2. Глобальный поиск (⌘K)
3. Адаптивность оставшихся таблиц (`/admin/*`, `invoices/import`,
   `invoices/import-files`, `analytics/items`)

Не начинать их без явного запроса — просто не давать им снова потеряться из
виду, как это случилось между первым аудитом и сейчас.

## Общий контекст

Смотри `ROADMAP.md` — единый бэклог продукта (этапы инфраструктуры +
открытый бэклог фичей + рыночный контекст от Discovery Team). Смотри
`README.md` — актуальное описание архитектуры и реализованных модулей.
Историю решений и найденных/закрытых находок безопасности проще всего
восстановить через `git log` — многие коммиты содержат подробный контекст
находки и фикса в теле сообщения.
